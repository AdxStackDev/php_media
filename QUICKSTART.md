# Quick Start Guide - IPTV Player

## 🚀 Get Started in 3 Steps

### Step 1: Access the Application
Open your web browser and navigate to:
```
http://localhost/iptv/login.php
```
(Adjust the path based on your web server configuration)

### Step 2: Login
Use the demo credentials:
- **Username**: `admin`
- **Password**: `1234`

Click the "Login" button.

### Step 3: Select a Plan
Choose from three subscription options:
- **Plan A**: $9.99 - 7 days (Weekly)
- **Plan B**: $29.99 - 30 days (Monthly) ⭐ Popular
- **Plan C**: $99.99 - 365 days (Yearly) 💎 Best Value

Click "Select Plan" on your preferred option.

### Step 4: Watch Channels! 🎬
You'll be automatically redirected to the channel page where you can:
- Browse 70+ channels
- Search for specific channels
- Filter by category (News, Entertainment, Movies, Music, Sports, Regional)
- Click "Watch Now" to start streaming

## 🔧 Troubleshooting

### Video Won't Play?
1. Check your internet connection
2. Try a different channel
3. Refresh the page (F5)
4. Clear browser cache

### Can't Login?
1. Verify credentials: `admin` / `1234`
2. Clear cookies and try again
3. Check if JavaScript is enabled

### Location Not Working?
1. Click "Allow" when browser asks for location permission
2. Check if location services are enabled in your browser
3. Try manually selecting regional channels from the sidebar
